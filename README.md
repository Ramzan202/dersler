# Otomatik Ders Dağılım Programı

📖 **Инструкция:** [на русском](docs/INSTRUKCIYA_RU.md) · **Kullanım kılavuzu:** [Türkçe](docs/KULLANIM_KILAVUZU_TR.md)

Настольное приложение для автоматического составления школьного расписания профессионально‑технических анатолийских лицеев Турции (Mesleki ve Teknik Anadolu Lisesi). Интерфейс на турецком языке, все данные хранятся локально в SQLite, расписание строит оптимизатор Google OR‑Tools CP‑SAT.

## Запуск (Windows 10/11)

1. Установите Python 3.11 или новее с [python.org](https://www.python.org/downloads/). При установке отметьте **Add python.exe to PATH** и **tcl/tk and IDLE**.
2. Дважды щёлкните `run.bat`.

`run.bat` делает следующее:

* проверяет, что установлен Python 3.11+ (`py -3` или `python`), и если нет, объясняет, что сделать;
* создаёт виртуальное окружение `venv`, если его ещё нет;
* проверяет, что в Python есть tkinter;
* устанавливает библиотеки из `requirements.txt`, только если их не хватает или файл изменился. Проверка идёт по хешу, сохранённому в `venv\.req_hash`, поэтому при следующих запусках ничего не переустанавливается;
* запускает `main.py`. Если что‑то пошло не так, выводит понятное сообщение, а подробности пишет в `data\hata_kaydi.log`.

Если при запуске появляется ошибка `abseil_dll.dll` / OR-Tools, не хватает библиотеки `MSVCP140.dll` из **Microsoft Visual C++ Redistributable (x64)**. Теперь `run.bat` сам ставит пакет `msvc-runtime`, который кладёт эти DLL в `venv`, а программа загружает их перед OR-Tools; права администратора для этого не нужны. `run.bat` предложит скачать и установить его сам, а вручную его можно скачать здесь: https://aka.ms/vs/17/release/vc_redist.x64.exe. После установки перезагрузите компьютер. Если ошибка останется, установите Python 3.12, удалите папку `venv` и запустите `run.bat` снова. Без OR-Tools программа всё равно откроется: данные вводить можно, не работает только автоматическое распределение.

Интернет нужен только при первой установке библиотек. При первом запуске база заполняется демо‑данными: 10 классов AMP9A–AMP12B, 23 учителя, 16 кабинетов и настоящие планы MEB (Bilişim Teknolojileri – Yazılım Geliştirme и Elektrik-Elektronik – Elektrik Tesisatları ve Dağıtımı). Все эти данные можно редактировать или удалить.

Запуск без `run.bat` (Linux/macOS или для разработки):

```bash
python -m venv venv && venv/bin/pip install -r requirements.txt -r requirements-dev.txt
venv/bin/python main.py
venv/bin/python -m pytest -q          # тесты
```

## Данные школы в репозитории

* `data/database.db` — полная база школы: 33 класса и 9 подгрупп, 135 предметов, учителя, 69 кабинетов, учебные часы, команды учителей, а также два варианта расписания: «Mevcut program (okul)» и «Optimize edilmiş program». Программа открывает её автоматически. Если у вас уже есть своя база в `data/`, сделайте её копию, прежде чем заменять файл.
* `docs/okul/` — описание алгоритма для руководства (`Algoritma_ve_Hesaplama.pdf`) и оба расписания в Excel.

## Импорт расписания школы (Excel «Sınıf Programları»)

«Ayarlar → 🏫 Okul programını içe aktar» загружает Excel-файлы с расписаниями классов в формате школьной программы распределения: блоки «Sınıf Kodu …», недельная сетка с объединёнными ячейками и список «Sıra / Ders / HDS / Mekan / Öğretmen Adı». Можно выбрать сразу несколько файлов (9, 10, 11, 12 классы). Из них создаются:

* **Расписание звонков.** Количество уроков и их время берутся из заголовка, например 16 уроков по 30 минут с 08:00.
* **Классы и подгруппы.** «ATP10A 1» становится группой ATP10A-1 основного класса ATP10A. Пока у группы урок, у основного класса урока быть не может. Окно занятий класса берётся из его текущего расписания.
* **Предметы по кодам** (MAT_9, 3BTT, …). Известные коды получают полные названия, остальные остаются кодами, их можно переименовать.
* **Учителя.** Специальность определяется по предметам, которые учитель ведёт. Записи «İşletme N» — это предприятие, а не учитель, поэтому они не импортируются.
* **Кабинеты.** У каждого кабинета задаётся «Aynı anda en fazla ders»: сколько групп помещается в него одновременно, по факту текущего расписания.
* **Урок класса.**
  * часы;
  * **команда учителей**: все ведут урок одновременно;
  * кабинеты: «hepsi aynı anda» — все используются одновременно группами, «birini seç» — для каждого блока выбирается один из списка;
  * деление на блоки;
  * код **объединения**: группы с одинаковым кодом учатся вместе, у одного учителя, в одно время.
* **İşletmelerde Mesleki Eğitim.** Предмет отмечен «Okul dışında»: учитель и кабинет для него не нужны.
* **Текущее расписание.** Сохраняется как вариант «Mevcut program (okul)». С него оптимизация стартует, и с ним сравнивается результат.

Все эти значения редактируются: в формах предметов, кабинетов и классов, в окне «Sınıflar → 📚 Dersleri» для уроков класса и через Excel-выгрузку и загрузку справочников («Sınıf Ek Dersleri», «Ana Sınıf», «Aynı Anda En Fazla», «Okul Dışında»).

Описание алгоритма для руководства школы (PDF, на турецком) собирается командой `python scripts/algoritma_pdf.py Algoritma.pdf data/database.db`. Если указать базу, в документ добавляется сравнение текущего и оптимизированного расписания.

## Учебные планы MEB и расписание звонков

В программу встроены официальные недельные учебные планы (Haftalık Ders Çizelgeleri) из рамочных программ MTAL, опубликованных на https://meslek.meb.gov.tr/cercevelistele.aspx?sinif_kodu=9&kurum_id=1. Данные лежат в `app/data/meb_cerceve_2026.json`:

* 57 направлений (alan) и 336 планов, по 9–12 классам;
* программы Anadolu Meslek, Anadolu Teknik, «İME 11. sınıfta başlar» и протокольные;
* 812 предметов.

Чтобы добавить план, откройте «Öğretim Planları → 📥 MEB», выберите Alan, Program, Dal и классы. Программа покажет предметы и часы, а затем создаст учебные планы и недостающие предметы.

* Часы «İşletmelerde Mesleki Eğitim» проходят на предприятии. Они записаны в примечании к плану, но в школьное расписание не ставятся.
* Выборочные часы добавляются как «Seçmeli Dersler» и «Seçmeli Meslek Dersleri». Их можно заменить конкретными выборочными предметами.
* 5 таблиц из PDF (по одному классу в 5 планах) прочитать однозначно не удалось. Эти классы не импортируются, и окно об этом предупреждает.

Скрипты извлечения данных лежат в `scripts/meb/`.

Расписание звонков по умолчанию — 6 уроков: 08:00–09:00, 09:15–10:15, 10:25–11:25, 11:35–12:35, 12:45–13:15, 13:15–13:50. Его можно изменить в «Ayarlar». Учтите: по планам MEB у класса 45 часов в неделю, а 6 уроков × 5 дней дают только 30 мест. Пока уроков в день меньше 9, проверка данных покажет ошибку «haftalık 45 saat ders var, ancak … 30 saat» и не запустит распределение.

### Редактор расписания

* Режимы просмотра: по классу, по учителю, по кабинету и по дню (сводная таблица всех классов).
* Предметы раскрашены по цветам; в ячейке видны учитель и кабинет; закрытые часы помечены.
* Чтобы перенести урок, щёлкните по нему, затем по целевому часу. Если там уже есть урок, они поменяются местами.
* По правому клику: сменить учителя (только из квалифицированных) или кабинет, закрепить урок (🔒 — оптимизатор оставит его на месте), удалить час, добавить урок в пустую ячейку.
* После каждого изменения расписание сразу перепроверяется на все жёсткие ограничения. Ячейки с нарушениями обводятся красным, ниже показывается список конфликтов; щелчок по конфликту открывает нужный класс.
* Варианты расписания: несколько вариантов хранятся одновременно, их можно переключать, копировать, переименовывать, удалять и сравнивать (метрики и число отличающихся часов).
* Экспорт в Excel и PDF.

## Алгоритм (app/core)

Задача моделируется как задача целочисленного программирования с ограничениями и решается CP‑SAT. Это настоящая оптимизация, а не случайная расстановка по свободным ячейкам.

**Переменные.** Для каждого урока *k* (пары класс × предмет):

* `s[k, L, d, p]` — блок длиной *L* часов начинается в день *d* с урока *p*;
* `z[k, вариант]` — выбранный вариант деления часов, например 3+3+3;
* `y[k, t]` — урок ведёт учитель *t*, причём один учитель ведёт все часы предмета в классе;
* `r[k, room]` — урок проходит в кабинете *room*;
* `a[k, t, слот]` и `b[k, room, слот]` — связывают учителя и кабинет с конкретным часом.

**Жёсткие ограничения** (`constraints.py`), нарушать их нельзя:

1. у класса не больше одного урока в час;
2. у учителя не больше одного урока в час;
3. в кабинете не больше одного класса в час;
4. каждый предмет получает ровно положенное число часов;
5. урок ведёт только квалифицированный учитель: предмет есть в списке учителя или совпадает branş, либо учитель закреплён за классом;
6. нет уроков в недоступные дни и часы класса (например, AMP12A учится только в понедельник и вторник);
7. нет уроков в закрытые часы учителя;
8. нет уроков в закрытые часы кабинета;
9. и 11. уроки только внутри сетки школы и дневного лимита класса;
10. если кабинет обязателен, используется только подходящий по типу, явному списку и вместимости;
12. соблюдаются лимиты учителя в день и в неделю (и минимум в неделю, если он задан);
13. деление на блоки: только разрешённые варианты, без запрещённых, с ограничением длины блока; по умолчанию один блок в день, а при разрешении нескольких блоков они не могут стоять вплотную;
14. закреплённые уроки остаются на своих местах.

**Мягкие ограничения** (`optimizer.py`) входят во взвешенную целевую функцию. Каждый вес настраивается в «Ayarlar» от 0 до 10, и изменение веса меняет результат:

* сложные предметы ставятся в начало дня (вес растёт со сложностью);
* физкультура — в конец дня;
* учитывается предпочтительное время предмета (утро или после обеда);
* нагрузка учителей одного branş выравнивается (минимизируется разница между максимумом и минимумом);
* минимизируются окна у учителей и у классов;
* ограничивается число сложных часов в день у класса;
* выравнивается дневная нагрузка класса и учителя;
* ограничивается число уроков подряд у учителя;
* учитываются предпочтительные дни учителя;
* предпочтительный вариант деления, например 3+3+3 для Web Tabanlı Uygulama Geliştirme.

**Запуск.** Сначала `validator.py` проверяет исходные данные. Он отделяет ошибки данных (у класса нет плана, у предмета нет учителя, часов больше, чем времени у класса, учитель перегружен, не хватает кабинетов или учебных дней) от предупреждений. При ошибках оптимизация не запускается. Затем решатель работает в отдельном потоке: окно показывает прогресс, число найденных решений и текущую оценку, расчёт можно остановить. Если остановить расчёт или исчерпать время, сохраняется лучшее найденное решение, и оно тоже удовлетворяет всем жёстким ограничениям. Можно взять текущий вариант как стартовое решение и сохранить закреплённые уроки.

**Если расписание невозможно**, оно не создаётся. `scheduler.py` заново строит модель, в которой каждая группа жёстких ограничений включается своим литералом‑допущением. CP‑SAT возвращает противоречивое подмножество групп, оно сокращается до минимального и переводится в понятный текст. Например:

> AMP12A sınıfının Türk Dili ve Edebiyatı dersi için 4 saat yerleştirilemiyor.
> Öğretmen Ayşe Yılmaz: kapalı saatleri (18 saat) ders yerleştirmeyi engelliyor.
> AMP12A sınıfının okul günleri/saatleri (18 saat müsait) yetersiz.

`conflicts.py` независимо проверяет любое расписание, в том числе после ручных правок. `workload.py` строит отчёты: распределённые и нераспределённые часы, конфликты, нагрузку учителей, среднюю нагрузку по branş, занятость кабинетов, нагрузку классов по дням и окна.

## Excel

«Ayarlar → Tüm verileri Excel'e aktar» сохраняет книгу, которую можно отредактировать и загрузить обратно через «Excel'den içe aktar». Записи сопоставляются по названию: существующие обновляются, новые добавляются. Перед импортом автоматически делается резервная копия. Листы:

| Лист | Колонки |
|---|---|
| Dersler | Ad, Kısa Ad, Varsayılan Saat, Sınıf Düzeyi, Alan, Dal, Branş, Zorluk (0-2), Fiziksel Etkinlik, Tercih Edilen Zaman, Derslik Türü, Derslik Zorunlu, En Küçük/Büyük Blok, İzin Verilen/Yasaklı/Tercih Edilen Bölünme(ler), Aynı Gün Birden Fazla Blok, Seçmeli, Mesleki, Renk |
| Derslikler | Ad, Tür, Kapasite, Donanım, Alan, Uygun Dersler, Notlar |
| Öğretmenler | Ad Soyad, Branş, Günlük/Haftalık En Fazla, Haftalık En Az, Art Arda En Fazla, Tercih Edilen Günler, Dersler, Notlar |
| Öğretim Planları | Plan, Sınıf Düzeyi, Alan, Dal, Program, Ders, Saat (одна строка на предмет) |
| Sınıflar | Ad, Sınıf Düzeyi, Alan, Dal, Program, Öğretim Planı, Sınıf Dersliği, Öğrenci Sayısı, Haftalık Saat, Günlük En Fazla, Okul Günleri, Notlar |
| Sınıf Ek Dersleri | Sınıf, Ders, Saat, Sabit Öğretmen |
| Müsaitlik | Tür (Öğretmen/Derslik/Sınıf), Ad, Gün, Kapalı Saatler (`1-3, 5` или `tümü`) |

Форматы значений: дни пишутся как `Pazartesi, Salı`; списки разделяются `;`; флаги — `Evet` или `Hayır`; варианты деления — `3+3+3; 2+2+2+3`. Пустой шаблон: «Boş Excel şablonu».

Экспорт расписания («Ders Programı → Excel») создаёт лист со сводным расписанием школы, листы для каждого класса, учителя и кабинета и отчёт о нагрузке учителей. PDF для печати («PDF») формируется по классам, по учителям или по кабинетам; шрифт поддерживает турецкие символы.

## Сохранение данных

* Каждое изменение сразу записывается в `data/database.db`, поэтому при закрытии программы ничего не теряется.
* Резервная копия делается автоматически при первом запуске за день (последние 20 хранятся в `backups/`), а также вручную, перед импортом и перед восстановлением.
* «Yedekten geri yükle» восстанавливает данные из копии; перед этим сохраняется текущее состояние.

## Тесты

* деление на блоки;
